# 2026-09-29 · V84

## 用户反馈（三条）
1. 接管态右键新建文件夹/文本文档「半天不出结果」；关闭整理后瞬间创建。
2. 整理好的桌面过一会儿「快捷方式积压变形跑到格子下面」；点整理（登记 1 项）后恢复。
3. 列数太多（真机 6 格排 5 列、每列 ~176px）：「搞成那么多列，却空了大量的空白，格子宽度反而压缩到文件名都看不清了」「这部分完全可以合并到一列里面」。

## 根因与修法
- **①新建慢**：`schedule_takeback` 旧逻辑菜单收起后 200ms 一查，`menu_open()||label_editing()` 双 false 就收回；而 Explorer 是菜单关闭**之后**才建目录+进改名（几百毫秒延迟）⇒ 编辑框被一起藏回隐藏视图 ⇒ 用户看到「没反应」。
  修：收回前要求「安静满 `HANDOFF_QUIET_GRACE`=1.5s」**或**「见过编辑框（`saw_edit`）且它结束」——普通右键最多晚 1.5s 收回；真新建则回车后 ~150ms 即收回。
  日志佐证：今天 13:20:56–59 只有 3 秒借出周期（点到新建后编辑框没出现就被收回）。
- **②积压变形**：`syncDesktop` 只 `refreshLoose` 从不重排；而 `grid_loose_list` 的竖条矩形是**实时**的（条目多→多铺一列→变宽），格子落位还停在上次重排 ⇒ 竖条新列压到「文件」格上。
  修：`fetchLoose(announce)`（GridOverlay.tsx）：快照 diff（`looseSnapRef`），竖条 width 变了→`relayoutSoon()`；有新文件→顶部提示「新文件…已进入未归类竖条」+ `scrollIntoView`（条目加 `data-path`）。`refreshLoose` 变为不播报包装。
- **③列数**：`pick_columns` 重写。两代反馈合成一个判据：**全部候选（k=1..=capacity × 自然/夹宽）里取 `min(横向填充率, 纵向填充率)` 最大**；平局 k 小、自然宽优先。
  - 09-23「补丁洞」（18 项独占列+501px 空）= 纵向填充低 → 被 min 拉掉；
  - 09-29「5 列窄格」= 纵向只填 717/968 → 同样被拉掉。
  - 真机 6 格 920×968：旧 5 列（占高 717）→ 新 **2 列自然宽**（tallest 719，无一夹窄）。

## 教训
- **「出结果」不等于「建了文件」**：接管态下新建结果的可见性链路 = 借出时机 → 改名编辑框 → 收回 → 重扫 → **竖条播报/滚动定位**，每环都可能让用户误判「没生效」。
- 竖条矩形实时、格子落位滞后 = 隐性不同步；凡是「实时算的一方」变化时必须触发重排。
- 两代用户反馈冲突时，找能把两个畸形**统一否掉**的判据（min 双轴填充率），而不是二选一。

## 用户反馈（附截图）
1. 「格子应该**从右往左**开始排，而不是从左到右，排完后剩余空间给快捷方式等不整理的图标部分」。
2. 「排列不饱满：上面是宽的、下面放一个小格子**宽度没有占满**……合理利用空间才好看」。

## 根因与修法（全在 `content_plan_in` ④ 落位段）
- **右锚定**：`right` 从 band 右沿起，每摆一列向左退一道缝 → 第一列（最大格）贴便签/工作台一侧，剩余空间留左边给未归类竖条。仍是内容纯函数 ⇒ 幂等不破；与带下空间「band_b x > band_a x」纪律不冲突（band_a 最右列右沿 = zone 右沿 < band_left）。
  ⚠️ 初版写成 `x = 右沿 − 总宽` 再往左摆 —— 那是块**左**端位置，整块左溢（测试 x=−57、重叠实锤）。正确写法是「右沿递减」。
- **列内撑满**：列宽 = 该列最宽格；窄格撑到列宽并 `box_height_at` 按新宽重算高（只会更矮）。⚠️ `items[order[i]]` 才是条目数下标（heights/widths/slots 按摆放序位置编号）。只**撑宽**不**夹窄**——V71 底线保留。
- 测试语义翻转：3 条「宽度==自然宽」→「**不许窄于**自然宽」；2 条引擎级「第一列贴左沿」→「最右列贴右沿」（zone_right = min(widget x) − GAP 或 right_edge）；`an_engine_placed...` 手工格期望方向「上方或左侧」→「上方或**右侧**」。
- 新增 `columns_anchor_right_and_narrow_boxes_fill_the_column_width`（500 宽逼单列，钉右锚定+撑满+幂等）。

## 教训
- **同文件多处 Edit 必须串行**（并行两个 Edit 打同一文件，第二个静默覆盖第一个——small_boxes 断言丢了到测试红了才发现，CONVENTIONS 早有此条，违反了）。
- 落位锚定算术：「先摆再退」与「从块左端起步」混用 = 整块溢出；写完先用引擎级测试（真机参数）验坐标符号。

**关键技术决策（v2 增量）**：
- 跨平台：Tauri 2 单一代码基座同时出 Win + macOS（`.msi`/`.exe` + `.dmg`），差异收敛到 `src/platform/` 与 `src-tauri/src/platform/{windows,macos}`（PlatformOps trait + cfg 分实现）
- **持久化修订**：数据层从 store(JSON) **切换为 SQLite（tauri-plugin-sql）**（便签/待办/剪贴板/历史/整理计划，高频写+FTS 检索）；store 降级为仅存配置（settings/模块开关/Pro 标记）
- **可扩展性架构**：模块（ModuleMeta）+ 功能（CommandMeta）双层注册，`import.meta.glob` 自动发现，新增功能零框架改动；扩展点分层 L1 内置（本期）/ L2 官方扩展包（仅接口）/ L3 第三方插件（不做）
- 多窗口：WindowManager + WindowKind（main/settings/note-{id}/clip-quick/organizer），便签一便签一窗、几何持久化
- 打包：Win 用 WebView2 bootstrapper + 缺失检测；mac 走 Developer ID 签名 + 公证 + staple；包体积目标 Win <30MB / mac <40MB
- 商业化：核心效率与整理永久免费，Pro 买断制为主（截图/OCR/PDF/密码管理/批量等增强）；无广告无捆绑

**产品名候选**：万象/OmniDesk（推荐）、顺手/Handy；已排除「运维/工具箱/百宝箱」类窄词。

| # | 坑 | 根因 | 解法 |
| --- | --- | --- | --- |
| 1 | PowerShell 直连全部 HTTPS 站点失败（"基础连接已经关闭"） | PS 5.1 基于 .NET Framework，**不读 HTTP_PROXY/HTTPS_PROXY 环境变量**；本机有沙箱代理 `127.0.0.1:54735` | 显式传 `-Proxy http://127.0.0.1:54735`；TCP 443 一直通，别误判为断网 |
| 2 | `rustup-init` 反复报 `os error 183`（文件已存在） | `.cargo\bin` 存在**预先的 0 字节 `rust-analyzer.exe`**；rustup 创建 proxy 链接时失败并留 0 字节残留，自我冲突 | 用 `fsutil hardlink create <目标> rustup.exe` **手动造齐 13 个 proxy**（cargo/rustc/rustdoc/rustfmt/cargo-clippy/clippy-driver/...），再只让 rustup 干 `toolchain install` |
| 3 | Rust CDN 直连不通 | `static.rust-lang.org` 被拦 | `RUSTUP_DIST_SERVER=https://mirrors.tuna.tsinghua.edu.cn/rustup`（+`RUSTUP_UPDATE_ROOT=.../rustup/rustup`），27 秒装完 |
| 4 | cargo 拉 crates 报 `CRYPT_E_REVOCATION_OFFLINE (0x80092013)` | Windows schannel 要联网校验证书吊销，吊销服务器不可达 | `~/.cargo/config.toml` 加 `[http] check-revoke = false`（或 `CARGO_HTTP_CHECK_REVOKE=false`） |
| 5 | winget 装 VS BuildTools 失败（msstore 源超时） | winget 源不可达 | 用代理下载 `https://aka.ms/vs/17/release/vs_BuildTools.exe` 引导器 + `--quiet --wait --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended`，**成功** |

## 一、已决策（团队按默认推进，可回改）

| # | 决策项 | 采用值 | 理由 | 来源 |
| --- | --- | --- | --- | --- |
| D1 | 桌面运行时 | **Tauri 2.x（Rust）** | 包 <20MB 量级、内存低、全局快捷键/托盘/自启/更新为一等公民插件；前端可复用网页版 React | ARCHITECTURE ADR-1 |
| D2 | 前端 UI 方案 | **React 18 + TS + Vite + Tailwind 3 + shadcn/ui(Radix)**，不引入 MUI | 与网页版同源便于迁移；制品小、无 runtime CSS-in-JS 开销 | ARCHITECTURE ADR-2 |
| D3 | 本地持久化 | **`tauri-plugin-store`（JSON）**，不用 localStorage、暂行 SQLite | 数据量小、无关联查询；Rust 侧也能读写；localStorage 与 WebView 同生共死且 5MB 上限 | ARCHITECTURE ADR-3 |
| D4 | 目标平台 | **仅 Windows 10 1809+ / 11（x64）** | 先把单平台做透，不做跨平台抽象 | PRD Q2 |
| D5 | 云同步 / 账号 | **不做**（无账号、无后端、无云） | 与「离线、隐私」定位一致；大幅降低复杂度 | PRD Q3/Q4 |
| D6 | 主界面形态 | **命令面板优先**，不预置分类宫格 | 这是桌面版与网页版最大的体验差异 | PRD Q6 |
| D7 | 插件系统 | **不做**（但保留可扩展的工具注册表） | 避免过度设计；注册表已支持低成本新增工具 | PRD Q7 |
| D8 | 默认全局快捷键 | **`Alt+Space`**（可自定义、可冲突检测） | 单手可达、不与常见快捷键冲突；输入法冲突可改键 | PRD Q5 |
| D9 | 敏感工具处理 | 密码/密钥类 **默认不写历史与剪贴板历史**，数据不出本机 | 隐私优先 | ARCHITECTURE 9.3 |
| D10 | 追踪/上报 | **不集成任何统计**；仅写本地日志文件 | 与「无追踪、离线」定位一致 | TASKS Q8 |
| D11 | 深色主题 | MVP **先做浅色扁平**，深色用 `dark:` 令牌预留不阻塞 | 聚焦 MVP，减少工作量 | TASKS Q2 |
| D12 | 剪贴板监听默认值 | **默认开启智能识别，默认关闭历史记录**，用户可一键开 | 兼顾体验与隐私观感 | TASKS Q3 |
| D13 | 自动更新 | **默认静默检查**，可关闭、可跳过版本 | 提升可维护性，同时尊重离线定位 | TASKS Q4 |

3. 进入开发阶段后，本文档作为「设计契约」，任何偏离需在此登记。

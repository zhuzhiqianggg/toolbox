## 1. 产品定位与愿景

### 1.1 一句话定位

> **一个「随手一按就出来」的 Windows 桌面工具箱**：常驻托盘、全局快捷键秒开，把运维/开发最高频的 20 个工具做成「离线、零打开成本」的本地能力。

### 1.2 要解决的核心问题（来自用户原话）

| 用户痛点 | 现状（网页版） | 桌面版如何解决 |
| --- | --- | --- |
| 「实用性不强」 | 50 个工具里大量是低频/凑数的，真正常用的十几个被淹没 | **做减法**：砍掉/降级一半，把高频工具做深、做快 |
| 「用起来不方便」 | 每次要开浏览器 → 找网址/书签 → 选分类 → 点工具 | **做入口**：全局快捷键直接呼出命令面板，输入 1~2 个字即达 |
| 「网页版本使用也不方便」 | 无法处理本地文件、无法与系统交互、断网不可用 | **做系统集成**：拖拽本地文件、剪贴板感知、托盘常驻、离线可用 |

### 1.3 桌面形态的本质差异（这是本产品的立身之本）

| 维度 | 网页版 | 桌面版（关键增益） |
| --- | --- | --- |
| **打开成本** | 开浏览器→找书签→点分类（3~5 步） | **1 个快捷键**（`Alt+Space`）→ 输入关键词 |
| **常驻性** | 关掉即消失 | **托盘常驻**，随时可用，随时退出 |
| **离线** | 断网 = 白屏（部分工具依赖后端） | **100% 本地化**，无网络照常工作 |
| **本地文件** | 只能上传，受大小/隐私限制 | **拖拽/右键**直接处理本地文件（哈希、编码检测、对比、重命名） |
| **系统集成** | 无 | 剪贴板监听、全局快捷键、右键菜单、开机自启、系统托盘通知 |
| **速度** | 首屏受网络与 CDN 影响 | **窗口秒开**（目标 < 300ms 首帧），无网络等待 |
| **隐私** | 数据可能经后端/第三方 CDN | **敏感数据（JWT/密钥/密码）永不出本机** |

> **一句话总结差异**：网页版是「一个你要去访问的网站」，桌面版是「一个随叫随到的工具」。

## 2. 目标用户与核心场景

### 2.1 目标用户画像

| 画像 | 描述 | 占比预估 |
| --- | --- | --- |
| **主力用户** | 全栈开发 / 运维工程师（本人画像：Django + Vue），日常联调、排障、写脚本 | 70% |
| **次要用户** | 后端 / DevOps / SRE，频繁处理配置、密钥、日志 | 20% |
| **边缘用户** | 前端 / 测试，偶尔需要 JSON、时间戳、UUID、二维码 | 10% |

**共同特征**：键盘流、追求效率、讨厌多一步点击、重视隐私（不信任把 token 贴到第三方网站）。

### 2.2 核心使用场景（≥5）

| # | 场景 | 用户动作 | 桌面形态的增益 |
| --- | --- | --- | --- |
| S1 | **联调时快速解一个 JWT / 时间戳** | 复制 token → 按 `Alt+Space` → 输入「jwt」→ 回车 → 结果自动从剪贴板填充 | 剪贴板直达，无需手工粘贴；离线可用，token 不外泄 |
| S2 | **生成一个强密码 / 密钥** | 快捷键呼出 → 「pwd」→ 调长度/字符集 → 一键复制 → 场景结束 | 3 秒完成；历史记录可回溯；永不联网 |
| S3 | **对比两段配置差异** | 拖入两个本地文件（或粘贴两段文本）→ 差异高亮 | 直接读本地文件，无需上传；支持大文件 |
| S4 | **格式化排查一段 JSON 报错** | 从日志/终端复制 JSON → 呼出 → 「json」→ 自动识别并格式化/定位错误行 | 剪贴板感知自动推荐「格式化 JSON」，零输入 |
| S5 | **写 Docker/k8s 配置** | 呼出 → 输入「compose」/「cron」/「nginx」→ 填参数 → 生成 YAML → 复制 | 本地模板库离线生成，比查文档快 10 倍 |
| S6 | **排查端口被谁占用** | 呼出 → 「端口」→ 输入 8080 → 列出 PID + 进程名 → 一键结束进程 | 纯桌面能力，网页永远做不到 |
| S7 | **校验本地文件哈希/改 hosts** | 拖入文件算 SHA256；或一键打开 hosts 编辑并保存 | 系统级集成，网页版无法企及 |

> 结论：桌面版的胜负手不在「工具数量」，而在 **S1/S2/S4 这类「3 秒内完成的动作」的入口效率**。

## 3. 核心体验设计

### 3.1 交互主循环（这是全产品最重要的设计）

```
[任何界面] --按下 Alt+Space--> [命令面板浮层] --输入关键词--> [命中工具] --Enter-->
[工具在浮层内/独立轻窗口打开] --操作--> [一键复制结果] --Esc--> [退回到原界面]
```

- **呼出即用**：`Alt+Space` 全局快捷键（可自定义），窗口**居中浮出**、**失焦自动隐藏**（可选），不打断当前工作流。
- **命令面板优先**：默认不展示 50 个工具的分类宫格，而是一个**搜索框 + 最近使用 + 收藏**。用户输入即模糊匹配工具名/别名/拼音首字母（如「sjc」→ 时间戳）。
- **首字母/别名映射**：高频工具预置短别名（`ts`→时间戳、`json`、`pwd`、`diff`、`b64`、`jwt`）。

### 3.2 桌面专属体验要素

| 能力 | 设计说明 | 优先级 |
| --- | --- | --- |
| **全局快捷键呼出** | 默认 `Alt+Space`；可改键；冲突时提示并引导更换 | P0 |
| **系统托盘常驻** | 单击显示/隐藏主窗口；右键菜单：打开/设置/退出；关闭主窗口 = 最小化到托盘 | P0 |
| **轻量窗口秒开** | 优先复用常驻进程，避免重复冷启动；目标首帧 < 300ms | P0 |
| **一键复制** | 所有结果区都有一键复制；复制后 toast 轻提示 | P0 |
| **剪贴板感知建议** | 监听剪贴板，识别「看起来像时间戳/JSON/JWT/Base64/URL」的内容，在命令面板顶部提示「检测到 JWT，是否解码？」 | P1 |
| **剪贴板历史** | 最近 N 条复制记录，支持搜索、置顶、清空 | P1 |
| **历史记录** | 每个工具保留最近输入/输出（可开关），跨重启持久化；敏感工具（密码/密钥）默认不记录 | P1 |
| **离线可用** | 所有工具本地计算，无任何网络依赖；UI 明确「离线可用」 | P0 |
| **开机自启** | 可选开关，默认关闭 | P1 |
| **自动更新** | 静默检查 + 提示更新，可关闭 | P1 |

### 3.3 效率设计原则

1. **零粘贴**：能从剪贴板/选中文本拿到的，绝不要求用户手工粘贴。
2. **零跳转**：工具在浮层内就地完成，不新开页面。
3. **零决策**：默认参数即最优（时间戳自动识别秒/毫秒；JSON 自动格式化）。
4. **可键盘闭环**：`↑↓` 选择、`Enter` 执行、`Esc` 退出、`Ctrl+C` 复制，全键盘可用。

## 4. 工具清单与取舍决策（重点）

### 4.1 判断标准

每条工具按 5 个维度打分取舍：

1. **是否高频**（日常是否天天用到）
2. **是否真实用**（不是凑数、不为做而做）
3. **是否适合桌面**（本地文件/系统集成/秒开优势是否明显）
4. **是否强相关「运维/开发」定位**
5. **是否已有更优替代**（系统自带 / IDE 内置 / 搜索引擎 / 命令行更顺手）

决策档位：**保留 P0**（MVP 必做）｜**保留 P1**（重要，紧随其后）｜**降级 P2**（有机会再做）｜**砍掉**（不做）。

### 4.2 全量工具决策表

#### A. 文本与数据处理

| 工具 | 决策 | 理由 |
| --- | --- | --- |

| CSV ↔ JSON | 保留 P1 | 数据处理常用；本地大文件转换优于上传 |
| YAML ↔ JSON | **保留 P1** | k8s/Docker/CI 配置刚需，运维强相关 |
| JSON → TypeScript | 保留 P1 | 前端/联调高频，接口对接提效明显 |
| SQL 格式化器 | 保留 P1 | 后端高频；比在线工具隐私更好 |
| XML ↔ JSON | 降级 P2 | 低频，企业遗留系统才用 |
| JSON Schema 生成器 | 降级 P2 | 低频、偏专业 |
| 数据脱敏（手机/身份证/邮箱等） | 保留 P1 | 分享日志/数据前脱敏，运维场景真实存在 |
| 文本模板替换 | 降级 P2 | 低频，脚本/编辑器可替代 |
| 文本统计 | 降级 P2 | 低频，编辑器自带 |
| 文本去重排序 | 降级 P2 | 低频，`sort/uniq`、编辑器自带更顺手 |
| 大小写转换（12 种命名） | 降级 P2 | 命名转换对开发有用但低频；可并入「文本」小工具 |

| --- | --- | --- |

| 文件编码检测 | 保留 P1 | **桌面专属增益**：直接读本地文件判断 GBK/UTF-8 |

### 4.3 两端清单（重点结论）

**「实用性强」——必须做扎实（P0 / 高频 P1）：**
> 时间戳转换 · JSON 格式化/转换 · 密码生成器 · 文本差异对比 · Base64 编解码 · JWT 解码 · 哈希/文件哈希 · IP/CIDR 规划 · Cron 预览 · Docker↔Compose · 端口占用查询 · 命令速查 · 编码与换行符转换

**「实用性弱 / 该砍」——果断不做：**
> 单位转换器 · 科学计算器 · 简繁转换 · 文件大小转换 · Slug 生成 · 工作日计算 · 时区批量校验 · 数据中心功率

**「降级 P2」——先不做，看反馈再说：**
> XML↔JSON · JSON Schema · 文本统计/去重/模板 · HTML 实体 · ASCII 码表 · Basic Auth · HTTP 状态码 · MIME/UA/MAC · API 测试器 · Mock 生成 · Linux 信号/退出码 · 电力/容量规划 · 颜色选择器 · 图片转 Base64

> **量化取舍结论**：原网页版约 50 项工具 → **保留 P0 约 12 项、保留 P1 约 20 项、降级 P2 约 20 项、直接砍掉约 8 项**。MVP 聚焦在 **P0 的 12 个「杀手级」工具 + 命令面板入口**。

### 4.4 建议新增的桌面专属工具/能力（网页版做不到或做不好）

| 新增能力 | 说明 | 优先级 |
| --- | --- | --- |

## 6. UI 设计方向

**视觉风格**：浅色为主题（可跟随系统深色）、扁平、**少层级**、大量留白、克制的分割线；主色 1 个（建议蓝或青），圆角统一，图标线性简洁。字体优先系统中文字体（微软雅黑 / 思源黑体）。

### 6.1 主搜索面板（命令面板）— 核心界面

```
┌───────────────────────────────────────────────┐
│  🔍  输入工具名 / 拼音首字母 / 别名…            │  ← 自动聚焦，随打随搜
├───────────────────────────────────────────────┤
│  ⚡ 检测到剪贴板：JWT  Token   [ 解码 ]         │  ← 剪贴板智能建议（P1）
├───────────────────────────────────────────────┤
│  ★ 常用   时间戳   JSON   Diff   Base64  密码   │  ← 收藏/最近使用
├───────────────────────────────────────────────┤
│  ▸ 时间戳转换          ts · Timestamp          │
│  ▸ JSON 格式化         json · Format           │  ← 键盘 ↑↓ 选择
│  ▸ 文本差异对比         diff                   │
│  ▸ 密码生成器           pwd                    │
│  ...（模糊匹配结果）                            │
├───────────────────────────────────────────────┤
│  Enter 打开   ↑↓ 选择   Esc 关闭   ⌘ 设置       │
└───────────────────────────────────────────────┘
```

**信息架构**：单一输入框（搜索）+ 剪贴板建议条 + 收藏/最近行 + 结果列表 + 底部快捷键提示。**没有分类宫格**（这是与网页版最大的不同）。

### 6.2 工具详情页（就地浮层/轻窗口）

```
┌───────────────────────────────────────────────┐
│  ←  时间戳转换                         ★  🕘  │  ← 返回 / 收藏 / 历史
├───────────────────────────────────────────────┤
│  输入  [ 1730000000            ]  ⟳ 秒/毫秒     │  ← 单行即可完成主任务
│  ─────────────────────────────────────────    │
│  结果  [ 2024-10-26 12:53:20  (UTC+8) ]  📋    │  ← 结果区，一键复制
│        [ 2024-10-26 04:53:20  (UTC)   ]  📋    │
│  ─────────────────────────────────────────    │
│  ▸ 更多选项 / 批量 / 高级设置（默认收起）        │  ← 渐进披露，少层级
└───────────────────────────────────────────────┘
```

**设计要点**：输入区与结果区两栏并列（宽屏）；**主任务单行即可完成**；高级选项默认收起；结果区固定带复制按钮。

### 6.3 设置页

```
┌───────────────────────────────────────────────┐
│  设置                                         │
├───────────────────────────────────────────────┤
│  通用    快捷键  [ Alt+Space ]  修改           │
│          开机自启  ( ) 关  ( ) 开              │
│          主题     ( ) 浅色 ( ) 深色 ( ) 跟随   │
│  体验    剪贴板感知   [ ✓ 开 ]                 │
│          剪贴板历史   [ ✓ 开 ]   清除记录       │
│          历史记录     [ ✓ 开 ]   清除记录       │
│  关于    版本 / 自动更新 / 检查更新 / 反馈      │
└───────────────────────────────────────────────┘
```

**信息架构**：左侧或分组式 3 个区块（通用 / 体验 / 关于），每项为「标签 + 开关/输入」，避免多级子页面。

## 7. 非功能需求

| 类别 | 指标 / 要求 |
| --- | --- |
| **启动速度** | 冷启动到可交互 **< 1s**；全局快捷键呼出后首帧 **< 300ms**（进程常驻） |
| **安装包体积** | 目标 **< 80MB**（若用 Tauri）；若用 Electron 则 < 150MB（详见待确认） |
| **内存占用** | 托盘常驻空闲 **< 120MB**；单工具使用峰值 < 250MB |
| **离线能力** | 所有工具 100% 本地计算；断网无任何功能降级（不出现白屏/加载） |
| **隐私安全** | 敏感数据（JWT/密钥/密码/hosts）**永不上传**；不集成任何统计/追踪默认开启 |
| **快捷键冲突** | 注册失败或被占用时，明确提示并引导用户改键；提供「冲突检测」 |
| **单实例** | 二次启动仅唤起已有窗口，不新建进程 |
| **自动更新** | 启动后静默检查，有更新时轻量提示；支持「跳过版本」「关闭自动检查」 |
| **开机自启** | 可选，默认关闭；通过系统启动项/注册表实现，可一键取消 |
| **稳定性** | 崩溃自动重启到托盘；关键操作（结束进程、写 hosts、批量重命名）需二次确认 |
| **兼容性** | Windows 10 1809+ / Windows 11，x64；高 DPI 缩放正常 |
| **本地化** | 界面简体中文；时间戳/JWT 等支持多时区显示 |

## 附录 A：与网页版的复用建议（供架构师参考，非本 PRD 职责）

- **可复用**：各工具的核心算法/纯函数逻辑（格式化、编解码、生成器模板）、UI 组件思路、工具元数据（名称/分类/图标）。
- **需重做**：入口交互（浏览器路由 → 命令面板）、所有涉及「上传/下载」的 I/O（改为本地文件系统）、状态存储（localStorage → 本地持久化）。
- **不迁移**：SEO、sitemap、Webhook、依赖后端的任何工具。
